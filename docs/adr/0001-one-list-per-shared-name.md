# One list per shared name

The List belongs to its name: everyone who opens the same name sees and edits the
same list, and Items never move between Lists. We rejected the alternative of a
personal, device-local list that gets broadcast into whatever room is joined,
because switching rooms would leak one group's items into another group's list.
Consequence: switching to a different name means entering a different list — any
local carry-over of items on switch is a bug.
